# 有酸奶 Yak Yogurt｜个人用量采集工具 v2

本工具只统计这台电脑上可读取的 Claude Code 与 Codex 日志，供你预览并上报到自己的有酸奶账号。它不能覆盖其他电脑、已删除的日志或整个账号的全部用量。

## 准备

1. 安装 Node.js 22 或更新版本，在终端运行 `node --version` 确认版本。此工具没有第三方依赖，无需运行 `npm install`。
2. 解压采集工具，进入解压后的目录。
3. 在有酸奶网页完成邀请加入后，从个人中心下载自己的 `public-client-v2.json`。手动在工具目录中新建 `.runtime` 文件夹，把配置放进去；不要分享配置或其中的上报码。

## 先预览

在工具目录运行：

```text
node scripts/report-community.mjs
```

默认只预览，不读取个人上报配置、不联网、不上传，也不会创建身份。显式使用 `--preview` 效果相同；需要查看 JSON 汇总时可以加 `--json`。

## 确认后上报

```text
node scripts/report-community.mjs --submit
```

程序先展示同一份预览，再询问确认。上报只使用你个人中心签发的专属配置。非交互执行还需明确加 `--yes`；有日志未计入时默认停止，核对并接受不完整统计后才加 `--allow-incomplete`。

自定义配置名仅允许同一 `.runtime` 目录内的 `public-client-v2-<安全名称>.json`，例如 `--config public-client-v2-safe.json`。不要使用旧版上报配置。运行 `node scripts/report-community.mjs --help` 查看说明。

## 发送哪些数据

只发送日期、工具、模型、输入用量、输出用量、创建缓存用量、读取缓存用量，以及固定类别的诊断数量；专属来源编号和上报码仅用于账号上报。日志目录只读，不发送提示词、回答、文件路径、原始会话编号或原始日志。费用参考估算不会作为上报数据，也不是订阅账单。

上报码可以在个人中心撤销或重新签发。它代表你的上报身份，并非电脑硬件绑定；请只保存在你自己的电脑上。详情见 [隐私说明](PRIVACY.md)。
