    3. 按工具内 README 说明先预览，确认后再主动上报。

    邮箱验证码登录

    首次加入需要一次性邀请码。无需设置密码；邮箱用于验证身份，不会显示在公开榜单。

    公开资料与作品

    首版保留一个作品。下方资料保存后会公开显示，邮箱不会公开。

    电脑上报配置

    每人一份有效配置；这不是硬件绑定。更换配置后，旧配置会失效。

    请先用上方「下载采集工具」并解压，再下载个人配置。专用配置含密钥，请勿发给别人；把 public-client-v2.json 放入工具根目录的 .runtime 文件夹，再按 README 预览、确认后上报。

    统计口径与隐私

    • 日榜按北京时间的自然日展示；今天尚未结束，数字会随手动上报更新。全站明细与个人明细的范围分别标明。
    • 输入、输出、缓存写入、缓存读取四列互不重复；总量包含缓存读取，同时另列不含缓存读取的用量。
    • 没有所选日期的上报行时显示「未上报」，不把缺失记录写成零。明确上报了零用量，才显示 0。
    • 只接收日期、工具、模型和用量汇总，不接收提示词、回答、代码或本机路径。
    • 汇总来自本机可读取的日志，不代表整个账号的全部用量；参考估算不是实际账单。
